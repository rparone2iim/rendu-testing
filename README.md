# Le tournoi de tennis de l'école

Raphaël Parone

Code qui tient le score d'un match de tennis simplifié (un seul jeu ou un set de 4 jeux) écrit en TDD. Le résultat du match est envoyé au classement du tournoi.

**Stack** : TypeScript et Vitest

## Démarrer

```bash
npm install
npm test
```

Pour relancer les tests à chaque modification : `npm run test:watch`
